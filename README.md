# \# Gym Management System

# 

# A full-stack web application built to streamline fitness center operations—covering member subscriptions, trainer allocation, workout schedules, equipment inventory tracking, and payment processing.

# 

# > \*\*Project Context:\*\* Originally built as a Year 1 Semester 2 group project at SLIIT (mirrored from \[`Pethmin09/gym-management-system`](https://github.com/Pethmin09/gym-management-system)).

# 

# \## Tech Stack

# \- \*\*Frontend:\*\* React, JavaScript, HTML5, CSS3

# \- \*\*Backend:\*\* Java, Spring Boot, REST APIs

# \- \*\*Database:\*\* MySQL

# 

# \## Core Modules

# \- \*\*Member \& Membership Management:\*\* Member onboarding, subscription plans, and role-based dashboards (Admin \& Member).

# \- \*\*Equipment Inventory \& Maintenance:\*\* Full CRUD lifecycle for gym equipment, real-time status metrics (Total, Available, Broken), search/pagination, and file-based activity logging.

# \- \*\*Trainer \& Workout Schedules:\*\* Trainer profiles and structured workout plan assignments.

# \- \*\*Payments:\*\* Member payment workflows and transaction records.
